# URANUS Demo
نمونه تعاملی رابط کاربری فارسی و راست‌چین بر اساس بخش‌های سند نیازمندی URANUS.

## اجرا
فایل `index.html` را با مرورگر باز کنید یا در GitHub Pages منتشر کنید.

## محدودیت‌ها
تمام داده‌ها، موجودی‌ها، قیمت‌ها، تراکنش‌ها و سفارش‌ها ساختگی‌اند. هیچ پرداخت یا انتقال واقعی انجام نمی‌شود. این نمونه، اپلیکیشن Flutter نهایی یا Backend عملیاتی نیست. اعتبار خرید تا بررسی حقوقی غیرفعال است. قیمت‌های مرجع و ترتیب Sitra/Zarr نیازمند تأیید مالک محصول‌اند.
